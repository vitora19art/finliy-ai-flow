# Logo FINLIY

A imagem atual está em `logo.png.asset.json`, que aponta para a logo enviada.
Para substituí-la, envie outra imagem e peça para usá-la como logo: o topo e o menu usam a mesma imagem.
O componente de logo também aceita `src` para apontar para outra imagem.
Ao substituir a imagem, atualize o favicon com uma cópia quadrada de 64 × 64 px.
